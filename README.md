# FIELDNOTES / 003 - A Warning From Inside

An interactive editorial explainer built from @somewheresy's post
["Building a new machine for monitoring situations"](https://x.com/somewheresy/status/2098031774588711162).

A situation monitor for the September 2026 Anthropic resignation: Jacob Coxon quit
warning that labs are "racing straight to self-improving superintelligence and
gambling with our lives." Eight scroll-driven sections, a live-rendered suspended
core machine (zero-dependency pseudo-3D on canvas), a pressure slider, an exploded
alignment diagram, and a closing question: who gets to decide?

- Single `index.html`, zero dependencies, canvas 2D engine (octagonal ring stack,
  painter's algorithm, scroll-driven explode states)
- Sections 00-07: the warning, the researcher, the feedback loop, the race dynamic,
  the response, alignment in plain language, the limit of the evidence, your turn
- Quotes sourced from reporting by TechCrunch, Ars Technica, Wired, WSJ (Sep 9-10, 2026)
- Keyboard: arrows / j-k to move between sections
